> Status: **none are integrated yet.** No SDKs, keys or webhooks are configured. This page
> records what is planned and where each service will plug in. Placeholder variable names
> are listed (commented out) in `apps/api/.env.example`.

| --- | --- | --- | --- |

| Cloudflare Pages | Hosts the static web export | **MVP** | `apps/web` |
| Railway | Runs the Rails API, jobs | **MVP** | `apps/api` |
| PostgreSQL (Railway) | Primary DB + Solid Queue/Cache/Cable DBs | **MVP** | `apps/api` |
| Bunny Stream | Video hosting, HLS, signed playback | **MVP** | `apps/api` (signing), clients (player) |

| Cloudflare R2 | File storage (images, attachments) via Active Storage | Future | `apps/api` |

## Notes per service

### Google Identity (MVP)
- Web uses Google Identity Services (`accounts.google.com/gsi/client`) and posts the
  ID token to `POST /api/v1/auth/google`.
- Mobile uses `expo-auth-session` Google ID tokens the same way.
- Rails verifies tokens with the `googleauth` gem against `GOOGLE_OAUTH_CLIENT_IDS`.

### Cloudflare Pages (MVP)
- Build command: `pnpm install && pnpm --filter @top-dance/web build`; output
  `apps/web/out`. Node 22.
- Env: `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_API_URL`, optional
  `NEXT_PUBLIC_GOOGLE_CLIENT_ID`. Do **not** set
  `NEXT_PUBLIC_ENABLE_DESIGN_SYSTEM` in production.
- `public/_headers` sets security headers (CSP, HSTS, frame denial). The CSP allows
  `connect-src https://api.topdance.academy https://accounts.google.com`,
  `script-src`/`frame-src` for Google Identity Services, and
  `frame-src https://iframe.mediadelivery.net` (Bunny player).
- `_redirects` is generated by `scripts/post-export.mjs` for dynamic course/lesson URLs.

### Railway (MVP)
- Deploy `apps/api` with its `Dockerfile` (Thruster + Puma).
- Required env: `RAILS_MASTER_KEY`, `DATABASE_URL`, `CACHE_DATABASE_URL`,
  `QUEUE_DATABASE_URL`, `CABLE_DATABASE_URL`, `APP_HOST`, `APP_HOSTS`, `CORS_ORIGINS`,
  `MAILER_FROM`. Optional: `GOOGLE_OAUTH_CLIENT_IDS`, `WEB_ORIGIN`. Health check path: `/up`.
- Run Solid Queue as a separate service (`bin/jobs`) or set `SOLID_QUEUE_IN_PUMA=true`.

### Bunny Stream (MVP)
- Upload from ActiveAdmin (later), store only `provider_video_id`.
- Playback: Rails checks access with Pundit, then returns a short-lived token-signed
  embed/HLS URL. The library API key and token auth key stay server-side.

### Resend (MVP)
- Action Mailer delivery via SMTP or the `resend` gem; localized templates per
  `users.preferred_locale`. Requires domain DNS verification.

### Sentry (MVP)
- `sentry-ruby`/`sentry-rails` for the API, `@sentry/nextjs` (client-only, static export)
  for web, `@sentry/react-native` for mobile. Scrub PII; upload source maps in CI.

### Paddle (future)
- Account approval pending. Subscriptions will be modelled in Rails and updated only by
  verified Paddle webhooks; clients never mark a subscription active.

### RevenueCat (future)
- Wraps App Store / Play billing. Its webhooks update the same Rails subscription state.

### Cloudflare R2 (future)
- S3-compatible Active Storage service for images and downloadable materials.
